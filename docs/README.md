# GitHub Pages Dashboard

This directory contains the static SecurePipeline portfolio dashboard. It is designed for GitHub Pages and uses only HTML and CSS, so it can be published without a build server or backend runtime.

The dashboard presents the project architecture, DevSecOps pipeline, security controls, Kubernetes posture, and monitoring plan. It links back to the source repository and deployment documentation.

GitHub Pages hosts the project presentation only. The Flask application, Docker image, Kubernetes cluster, Prometheus, Grafana, Loki, and Promtail must run on Ubuntu or another server with the required runtime tools.
